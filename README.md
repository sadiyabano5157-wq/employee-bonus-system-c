# employee-bonus-system-c
C program to calculate employee bonus and final salary using if-else conditions.


# Employee Bonus System in C

This C program calculates:
- employee bonus
- final salary

based on employee experience using if-else conditions.

## Features
- 20% bonus for 10+ years experience
- 10% bonus for 5+ years experience
- no bonus otherwise

## Concepts Used
- if-else
- percentage calculation
- user input
